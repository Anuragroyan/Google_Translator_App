🌐 Language Translator

Language Translator is a React Native application that allows users to translate text between different languages using the Google Translator API. It provides a simple and intuitive interface for entering text, selecting source and target languages, and viewing translated results through API-powered communication.

✨ Key Features

* 🌐 Translate text between multiple languages
* 📝 User-provided text input
* 🔄 Source and target language selection
* 🔁 Switch source and target languages
* 📖 Display translated results
* ⚡ Fast API-based translation
* 🌍 Support for multiple language options
* ⚠️ Input and error handling
* 📱 Clean and responsive React Native UI
* 🌐 REST API integration

🏗️ Architecture & Workflow

The React Native interface collects the user’s text and selected source and target languages. The application sends the translation request to the Google Translator API and processes the API response to retrieve the translated text. The result is then displayed through the React Native interface.

🛠️ Tech Stack

React Native • JavaScript • Expo • Google Translator API • REST API • Axios • API Integration

▶️ Run the App

1. Install dependencies

npm install

2. Start Expo

npx expo start

3. Run on Android

npx expo start --android

4. Run on iOS

npx expo start --ios

5. Run on Web

npx expo start --web

🎯 Project Purpose

This project demonstrates how to build an API-driven translation application using React Native. It provides practical experience with REST API integration, asynchronous requests, language selection, response handling, error management, and building a clean mobile interface for real-time translation.
